# 🛒 Ecommerce ShopVerse

A full-stack microservices-based E-Commerce platform built using React.js and Spring Boot.

## 🚀 Project Overview

Ecommerce ShopVerse is a scalable online shopping platform that provides secure authentication, product management, cart operations, order processing, payment integration, and service discovery using a microservices architecture.

The application demonstrates enterprise-level software engineering concepts including:

* Microservices Architecture
* JWT Authentication
* Google OAuth Login
* Razorpay Payment Gateway
* Service Discovery using Eureka
* RESTful APIs
* React Frontend
* MongoDB Integration

---
