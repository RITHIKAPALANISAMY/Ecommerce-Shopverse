# 🛒 ShopVerse - Enterprise E-Commerce Platform

### Full Stack Microservices-Based E-Commerce Application

ShopVerse is a modern full-stack E-Commerce platform built using **React.js**, **Spring Boot Microservices**, **MongoDB**, **MySQL**, **JWT Authentication**, **Google OAuth**, **Firebase**, **Razorpay Payment Gateway**, and **Netflix Eureka Service Discovery**.

The project demonstrates enterprise-level software engineering practices through a scalable microservices architecture that supports secure authentication, product management, shopping cart operations, order processing, online payments, and administrative analytics.

# 🚀 Project Overview

ShopVerse is designed to simulate a real-world online shopping ecosystem where customers can browse products, compare items, manage shopping carts, place orders, make secure online payments, and track purchases.

Administrators can manage products, approve listings, monitor orders, analyze business performance, and oversee platform operations through dedicated dashboards.

Each service is independently developed and deployed, following modern microservices principles.
